bonsai-fold asks whether the depth redundancy that layer-pruning exploits in fp models survives an end-to-end move to 1.125 bits per weight. Using PrismML's Bonsai 27B public weights, it maps block-level redundancy, removes blocks, and merges blocks with novel operators that stay natively in sign/trit space (including a binary-pair-to-ternary "promotion merge" that produces heterogeneous-precision stacks), all training-free and reproducible on one 64 GB MacBook.
